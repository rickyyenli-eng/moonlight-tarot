# 🌙 Moonlight Tarot · 月光塔羅

線上塔羅抽牌站 —— 78 張韋特全套、正逆位、儀式感抽牌流程。

**線上網址：https://rickyyenli-eng.github.io/moonlight-tarot/**

## 頁面

- `index.html` — 抽牌站。三種牌陣（聖三角 / 時間流 / 二擇一），洗牌 → 扇形選牌 → 3D 翻牌，結果可一鍵複製文字或下載牌面分享圖
- `library.html` — 78 張牌義知識庫，可搜尋、依大牌與四花色分類

## 技術

純靜態網站，可直接以 GitHub Pages 部署。

## 牌圖版權

牌圖為 1909 年原版韋特塔羅（Rider–Waite–Smith，Pamela Colman Smith 繪），
著作權已到期並進入公有領域，圖源 [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck)。
